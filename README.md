# Earth Systems Simulation

A desktop application that simulates interactions between major Earth systems using Python and PyQt6.

The program allows the user to enter an average monthly temperature and observe how changes in temperature affect the atmosphere, hydrosphere, geosphere, and biosphere.

---

## Features

- Enter an average monthly temperature
- Simulates atmospheric conditions
- Calculates changes in air pressure
- Estimates cloud coverage
- Determines the chance of storms
- Determines precipitation type
- Simulates water temperature
- Calculates evaporation rate
- Identifies flooding or drought conditions
- Tracks surface temperature
- Tracks soil moisture
- Evaluates vegetation health
- Simulates plant, prey, and predator populations
- Displays results through an interactive PyQt6 graphical interface

---

## Technologies

- Python
- PyQt6
- Qt Designer
- Object-Oriented Programming
- Event-Driven Programming
